CS2 HUB — Fluid Redesign
===========================
Modernes, responsives One-Page-Design für ein CS2-Schulprojekt.

Dateien:
- index.html
- style.css
- script.js
- images/ (Persona-Bilder, sofern vorhanden)

Features:
- Fluides Dark-UI mit Lime-Akzent
- Sticky Navigation
- Scroll Progress
- Smooth Sections
- Interaktive FAQ
- Gameplay / Maps / Settings / Hardware
- Ausführliche Personas inklusive Jobs to be Done
- Responsive für Desktop, Tablet und Smartphone

Start:
index.html im Browser öffnen.
